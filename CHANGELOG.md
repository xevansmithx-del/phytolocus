# Changelog

All notable changes to PhytoLocus are documented here. The format follows Keep a Changelog, and the
project uses Semantic Versioning.

## [Unreleased]

### Added

- Initial public repository scaffolding and neutral synthetic fixture contract.
- Three-layer verification model for source contracts, locus reconciliation, and capsules.
- Conservative privacy scanner for public-release hygiene.

## [0.1.1] - 2026-08-13

### Fixed

- Corrected ToolUniverse 1.4.1 `return_schema` definitions to describe the inner success `data`
  payload, so `tu test` validates all three plugin tools without changing adapter error envelopes
  or scientific compiler behavior.

## [0.1.0] - 2026-08-13

### Added

- Alpha provenance-first plant locus reconciliation compiler.
- Planned `validate`, `compile`, and `validate-capsule` command surfaces.
- Deterministic five-document evidence capsule.
- Optional ToolUniverse 1.4.1 plugin surface.
